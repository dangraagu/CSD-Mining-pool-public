# v0.1.8 build matrix

Reference matrix for the prebuilt binaries shipped with a release. Each row is a
target/backend combination produced by CI and uploaded to the GitHub Release,
with its `SHA256SUMS` entry. The miner connects to the official CSD pool that is
compiled into the binary; there is no endpoint flag to set.

## Targets x backends

| OS         | Arch    | Backend | Artifact name                       | Notes                          |
| ---------- | ------- | ------- | ----------------------------------- | ------------------------------ |
| Windows    | x86_64  | CPU     | `csd-pool-miner-cpu.exe`            | default; no GPU toolchain      |
| Windows    | x86_64  | CUDA    | `csd-pool-miner-nvidia.exe`         | NVIDIA driver only (PTX JIT)   |
| Windows    | x86_64  | OpenCL  | `csd-pool-miner-amd.exe`            | AMD / other GPU                |
| Linux      | x86_64  | CPU     | `csd-pool-miner-linux-cpu`          | default; no GPU toolchain      |
| Linux      | x86_64  | CUDA    | `csd-pool-miner-linux-nvidia`       | NVIDIA driver only (PTX JIT)   |
| Linux      | x86_64  | OpenCL  | `csd-pool-miner-linux-amd`          | AMD / other GPU                |

The CPU build is the default and requires no GPU toolchain on the build host. The
CUDA build embeds a prebuilt PTX and JITs it through the NVIDIA driver at runtime,
so only the driver (not the CUDA Toolkit) is needed to run it.

## Build commands

```sh
cargo build --release                              # CPU-only (default)
cargo build --release --features cuda              # NVIDIA
cargo build --release --features opencl            # AMD / other
cargo build --release --features "cuda,opencl"     # both; auto-pick best at runtime
```

## Smoke check

After building, confirm the binary can reach the pool and that every backend
agrees with the reference CPU hasher:

```sh
csd-pool-miner selftest        # cross-check backends + TCP-probe the pool (host:port)
csd-pool-miner devices         # list detected GPUs
```

`selftest` resolves and TCP-probes the compiled-in pool endpoint (`host:port`)
and reports PASS/FAIL without being fatal, so it is safe to run in CI before a
long mining run.

## Release artifacts

Each release uploads the binaries above plus:

- `SHA256SUMS` — checksums for every artifact (the auto-updater verifies a
  download against this **before** an atomic swap, and fails closed otherwise).
- `csd-pool-miner-hiveos-<version>.tar.gz` — the HiveOS Custom-miner package.
